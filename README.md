# KTR Charitable Trust — Donation Website

This is an original charity donation journey inspired by the information architecture and functionality of modern NGO donation pages, including the reference Narayan Seva donation page.

## Included functionality
- Indian / NRI / Foreign donor selection
- One-time / monthly giving
- Country and currency selection
- Cause/purpose selection
- Preset and custom donation amounts
- Tax receipt preference
- Multi-step donor details form with validation
- Donation summary
- Payment-method selection
- Online-payment gateway placeholder
- Bank-transfer placeholder
- Responsive mobile navigation
- Success state and reset flow

## Important before production
Replace all placeholder KTR details, impact numbers, contact details, tax registration information and bank details with verified information.

For live payments, connect the final step to KTR's approved payment provider (e.g. Razorpay/Cashfree/other provider) and implement server-side payment verification and webhook handling. Do not put secret payment keys in browser code.
